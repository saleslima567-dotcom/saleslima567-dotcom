## Sobre mim

Sou Paulo Kauã Sales, do Ceará, e atualmente curso **Análise e Desenvolvimento de Sistemas na Uninassau**. Tenho interesse em desenvolvimento web e gosto de transformar ideias em aplicações úteis, cuidando tanto da experiência de quem utiliza quanto da lógica por trás de cada funcionalidade.

Venho desenvolvendo projetos que envolvem interfaces web, regras de negócio, integração entre frontend e backend, persistência de dados e publicação de aplicações. Meu objetivo é continuar aprendendo na prática e evoluir a cada projeto.

## Projetos em destaque

### Learn-Play — Plataforma de cursos online

Plataforma demonstrativa de cursos online com catálogo, busca, autenticação, perfis de aluno, professor e administrador, matrículas, aulas, acompanhamento de progresso e avaliações. O projeto também inclui painel administrativo, ambiente com Docker e uma camada de segurança com proteção CSRF, controle de acesso por perfil, limitação de requisições de autenticação, validação da API, cabeçalhos HTTP de segurança e auditorias automatizadas de dependências no GitHub Actions.

**Tecnologias:** React, TypeScript, Python, Flask, SQLAlchemy, PostgreSQL, Docker e GitHub Actions.

- [Ver repositório](https://github.com/saleslima567-dotcom/Learn-Play)
- [Acessar demonstração](https://learnplay-lzk9.onrender.com)

*Observação: pagamentos e reprodução de vídeos são demonstrativos; não há cobrança real nem hospedagem de vídeos.*

### Inventário de Softwares de TI

Sistema web de gerenciamento de softwares e licenças, com **cadastro de usuários, autenticação por sessão e inventário separado por conta**. Oferece CRUD completo, dashboard com indicadores de vencimento, pesquisa, filtros, ordenação, exportação CSV e backup JSON.

A interface utiliza **HTML, CSS e JavaScript puro**; a API REST roda no **Cloudflare Workers** e armazena os dados no **Cloudflare D1 (SQLite)**. O projeto possui testes automatizados, validações de segurança e integração de deploy pelo GitHub.

**Tecnologias:** HTML5, CSS3, JavaScript, Cloudflare Workers, D1 (SQLite), SQL, Wrangler e GitHub Actions.

- [Acessar sistema online](https://cadastro-de-inventario-de-softwares-de-ti.lokokaua567.workers.dev/)
- [Ver repositório e documentação](https://github.com/saleslima567-dotcom/Cadastro-de-Inventario-de-Softwares-de-TI.)

*Observação: projeto demonstrativo. Acompanhamento de vencimentos disponível no dashboard; notificações por e-mail e recuperação de senha ainda não foram implementadas.*
